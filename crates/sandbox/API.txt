# The public surface of buildclamp-sandbox.
#
# This file IS the promise. `crates/sandbox/tests/api.rs` compares the source against it
# and fails on any difference, in either direction — so enlarging what this crate keeps
# working forever is a line in a diff somebody looked at, rather than something that
# happened.
#
# Not everything here is reachable by a consumer: the scanner reads declarations out of
# the text rather than from rustdoc's JSON, which is nightly-only, so it also lists items
# declared `pub` inside a private module. That is the safe direction — an item that
# becomes reachable later is already written down, and the change shows up in `lib.rs`'s
# `pub use` lines, which are listed too.
#
# What is FROZEN, as opposed to merely listed, is in API.md, and `tests/frozen_api.rs`
# pins each of those at its exact type so the compiler enforces it.
